# shici-namer

从古典诗词里**摘现成的词**当名字。不算五格、不数笔画、不判五行吉凶。

```
「明月松间照，清泉石上流」  →  明月 · 清泉
```

名字本来就在诗里，不需要从字库拼。只摘句内**相邻**两字；
「清照」式的跨位组合属于拼字，不在机制内。

---

## 它解决什么问题

常见的起名工具做两件事：按笔画数算吉凶（五格三才），从字库里按五行拼字。
两件事各有问题：

**五格不成立**——1918 年日本人熊崎健翁开创，比唐宋早了近千年的人用不上它。
实测 20 个唐宋名字 0 个能过五格的筛子，范仲淹四格全吉却卡在三才相克。

**拼字不出好名**——「桢柏」「楷桐」是把两个木本植物堆在一起（同义堆叠），
它们在你我之前的方案里出现过，但在 116 万条真实姓名里**频次为 0**。

这个项目换成：**从文本摘词 + 真实人口校验**。

---

## 效果

历史上公认的好名字，现在排在它们该在的位置（全量 7 部书语料、35,303 个
候选上的实测名次，见 `docs/DECISIONS.md` D-007）：

| 名 | 出自 | 实测名次 | 改造前 |
|---|---|---|---|
| 呦呦 | 诗经·鹿鸣「呦呦鹿鸣」（屠呦呦） | **#263（前 0.7%）** | 被门槛挡掉 |
| 徽音 | 诗经·思齐「大姒嗣徽音」（林徽因） | **#880（前 2.5%）** | 被门槛挡掉 |
| 乔木 | 诗经·汉广「南有乔木」 | 前 4.8% | #558/16448 |
| 清扬 | 诗经·野有蔓草「子之清扬」 | 前 5.7% | 中游偏后 |
| 望舒 | 楚辞·离骚「前望舒使先驱兮」（戴望舒） | 前 5.7% | #8700/16448 |
| 思成 | 诗经·商颂「绥我思成」（梁思成） | 前 7.1% | 中游偏后 |
| 清泉 | 王维「清泉石上流」 | 前 7.5% | #11727/11857 |

而语料高频的平庸词（千里/四方/百年/一生/秋水）全部跌到最后 5%。

> 2026-10 起默认配置叠加了用户浏览偏好（D-010：人口门槛 ≥2、压叠字层、
> 响亮收尾优先）：聂·男全量下 乔木 #504、清扬 #687、修竹 #731、思成 #1079、
> 清泉 #1144；徽音被 ≥2 门槛挡在门外、呦呦回到叠字层。三项均为配置一行可回退。
每个名字都带：平仄（平水韵，含入声）、声母韵母、部首、真实人口频次、
是否名篇出处、全部出处（书名/篇名/作者/朝代/原句）。

## 安装

```bash
pip install -r requirements.txt
python data/fetch.py --check      # 检查数据是否齐全
```

数据约 300 MB（语料 + 116 万条姓名库），不随仓库分发。见 `data/README.md`。

---

## 用法

```bash
# 全量候选
PYTHONPATH=src python -m shici_namer --top 40

# 聂姓男孩
PYTHONPATH=src python -m shici_namer --xing 聂 --sex 男 --top 30 --csv 聂.csv

# 只要平仄交错的
PYTHONPATH=src python -m shici_namer --require-pingze --top 30
```

排序默认「名篇 + 独特性」优先（不撞名）；想换口味改 `config/default.yaml`
的 `rank.order` 即可，每个键都支持 `:asc`/`:desc` 方向后缀。

也可以当库用：

```python
from shici_namer import run

result = run(surname="聂", sex="男")
for c in result.top(10):
    print(c.name, c.pingze, c.sources[0].label(), c.sources[0].sentence)
```

## 输出字段

CSV 18 列：姓名 · 名 · 平仄 · 今调 · **全名声调** · 声母 · 韵母 · 部首 · 同部首 · 性别倾向 · 男女比 · 语料词频 · 真实人口频次 · 出处跨书数 · 首选出处 · 首选原句 · 全部出处 · **尾字洪细**

**没有「分数」列**。这是刻意的：加权综合分无法验证，容易变成另一种编造。
按任一维自己排——全部字段都给了。

## 设计取舍

| 选择 | 理由 | 代价 |
|---|---|---|
| 全量 2-gram 而非分词 | jieba 把「清泉石上流」切成 `清泉石/上流`，漏掉「清泉」 | 会产生「其道」「国之」这类伪词，需停用字表 |
| 真实人口频次而非笔画吉凶 | 可核对的事实 vs 1918 年的约定 | 只反映 1930–2008 的命名偏好，不反映当代 |
| 平水韵而非普通话四声 | 王安石在普通话里是平平平，平水韵是**平平仄**（石为入声） | 需要一份韵书数据 |
| 名篇 + 独特性排序而非频次降序 | 频次降序的榜首是「千里/百年/志刚」——陈词滥调与流行款（D-007） | 思成/清泉这类好名的客观天花板约前 4% |
| 名篇目录（唐诗三百首等）做经典度 | 选本收录可引用、可核对（蘅塘退士/朱祖谋/王逸） | 目录外的好出处（宋诗）暂无分级 |
| 地名碎片标记（语境全称判定 + 地名志） | 「武强」右邻永远是「縣」是可算的事实；民政部名录可引用（D-011） | 广德/崇礼 这类吉祥语县名一并垫后 |
| 同部首直接剔除（叠字豁免） | 「桢柏」「楷桐」是同义堆叠；「呦呦」是修辞典故 | 会误伤「江海」这类合理的同旁字 |
| 全名听感只降权不剔除（D-009） | 王维(2-2)/徽音(1-1) 是同调好名；三连同调与「陈恩」式连读只垫后 | 各维度偏好因人而异，`rank.order` 一行可调 |
| 不做综合加权分 | 权重无法验证 | 用户要自己看多维数据 |

完整口径见 `config/default.yaml`（每项都写了理由）与 `docs/SPEC.md`。
