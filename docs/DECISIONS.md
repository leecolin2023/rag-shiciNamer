## D-001 · 不做五格三才与笔画吉凶

**状态**：已采纳（不可回退，除非有新证据）

**背景**：最初的方案是按传统「五格剖象法」筛名字——康熙笔画 → 81 数理 → 三才配置。

**为什么推翻**：

1. **时代错位**。五格剖象法是 1918 年日本人熊崎健翁开创，1936 年由台湾留日学者白玉光译介回中文圈，1990 年代方晨等人在大陆以康熙笔画为基准规范化。而李清照生于 1084 年、王安石生于 1021 年——这套打分表比他们晚出现约 800 年。用晚 800 年的工具去评他们，本身就是错的坐标系。

2. **理论根基存疑**。辞书原文：「五格数理是依据姓名的笔画数和一定规则建立起来……**其立论方法不是基于中国传统易学的内容**，仅是相对结合了部分的内容而已。」

3. **实测反证**。拿 20 个唐宋名字跑五格筛子（四格全吉 + 三才吉）：**0 个通过**。
   - 李清照：人格 19 凶、外格 14 凶
   - 王安石：人格 10 凶
   - 白居易：人格 13 / 地格 16 / 总格 21 全大吉，**只差外格 9**
   - 范仲淹：四格全吉（人 21 / 地 18 / 外 13 / 总 33），**唯独卡在三才「土木金」相克**

4. **产物反证**。上一版按五格筛出的 14 个名字（楷桐、桢柏、熙桓、宣淇…），丢进 116 万条真实姓名库：**12 个频次为 0**——历史上从没有人叫过这些名字。而诗词摘词出来的名字，全部有真实人口记录。

**替代方案**：从文本摘词 + 真实人口统计排序。

**保留意见**：康熙**字典**本身是可靠的（字义、部首、反切），问题只在「拿笔画数当吉凶输入」。所以本项目仍用康熙数据的**部首**字段，但不用笔画数。

## D-002 · 用全量 2-gram，不依赖分词器

**状态**：已采纳

**背景**：`wrk226/get_chinese_name` 用 jieba（paddle 模式）分词 + 正则匹配「整词恰好 N 字」。
这是当时看到的最正确做法——它真的要求「成词」。

**为什么还要改**：分词器的切分错误会直接吃掉名字。

```
「清泉石上流」  jieba → 清泉石 / 上流      「清泉」丢失
```

王维《山居秋暝》里最关键的「清泉」就是这么丢的。而 2-gram 枚举 + 姓名库校验能捞回来：

```
2-gram → 清泉 / 泉石 / 石上 / 上流
校验    → 清泉（人口 95）✅
```

**代价**：会产生伪词。「其道」「国之」「以成」「有明」都通过了校验（它们在姓名库里真实存在，因为有人叫过），必须靠停用字表剔除。

**结论**：2-gram 的漏检率更低，代价（伪词）可用停用字表控制；分词器的漏检无法补救。

## D-003 · 不设综合加权分

**状态**：已采纳

**背景**：一开始想给候选算一个总分：`0.4×音韵 + 0.3×出处 + 0.3×罕见度`，方便排序。

**为什么不**：加权系数无法验证。0.4 和 0.3 是怎么来的？没有依据。
这种分数最终会变成另一种「看起来合理的编造数字」——而这恰恰是本项目要反对的东西
（参见 D-001 里对五格数理的批评：它也是「用一串数字代替依据」）。

**替代**：多键字典序排序，每一维都是可独立核对的客观量。
CSV 里 16 列全部保留，用户可按任一维自己重排。

**副作用**：用户体验上不如单一分数直观。接受。

## D-004 · 同声母/同韵母只标记，不排除

**状态**：已采纳（修正了一个早期错误）

**背景**：第一版把「名二字同声母」「同韵母」当硬性排除条件。

**为什么错**：双声（参差、清泉、仿佛）和叠韵（窈窕、逍遥、徘徊）是**汉语的修辞美**，
从《诗经》起就是主动使用的技巧。把它们当噪声删掉，是把美学特征误判为缺陷。

**证据**：「清泉」是 q-q 双声，被第一版误杀；改成只标记后进入候选（语料词频 568、人口 95）。

**保留的硬排除**：只保留「同部首」（同义堆叠）——因为「桢柏」「楷桐」这类
（桢=木柱、柏=柏树、楷=楷树、桐=梧桐）确实是两字同指一类事物，缺乏意象张力。

## D-005 · 排序不能用人口频次降序

**状态**：已采纳

**背景**：既然要用真实人口统计替代笔画吉凶，第一反应是按人口频次降序排——用得多的名字更"稳妥"。

**为什么错**：直接跑出来榜首是「志刚 / 晓东 / 建平 / 海峰 / 海龙 / 晓峰」——
那是 1950–1990 年代的命名潮流，不是文学品质。

**另外**：「建平」在语料里只出现在「況復建平家」一处，其实是**地名**；
它能进榜纯粹因为历史上有人叫这个名字。

**改法**：用 `corpus_freq`（语料词频）当**成词性代理**——真词在语料里反复出现
（「明德」185 次、「千里」7476 次），偶然相邻只出现一两次。
人口频次降为第二维参考。

**教训**：任何一个统计量都可能被误用。用之前先看它的分布长什么样。

## D-006 · 平仄标签用单字（平/仄/通/?）

**状态**：已采纳（测试驱动的修正）

**背景**：最初把两读字标为「两读」（两个字），导致 `len(pingze) != len(name)`。

**问题**：`"两读仄"` 是 3 个字符，但名字是 2 个字，逐位对齐会错位。
`tests/test_pipeline.py` 的正则断言立刻挂了（45 个 subtest 失败）。

**改法**：单字标签——`平` / `仄` / `通`（两读）/ `?`（韵书未收）。
不变量 I3：`len(pingze) == len(name)`。

**教训**：把「展示用的中文词」直接当数据结构字段，会在下游处处是坑。

## D-007 · 排序从「频次降序」改为「名篇 + 独特性」，门槛改双通道

**状态**：已采纳（2026-10，验收标准：公认好名排名靠前）

**背景**：用户反馈「取的名字不好听」。实测（诗经+楚辞，713 候选）：

| 词 | 旧排名 | 死因 |
|---|---|---|
| 徽音（林徽因） | 不在候选 | 人口 1 < 门槛 3 |
| 呦呦（屠呦呦） | 不在候选 | 人口 0；即使进来也被口+口 同部首剔除 |
| 望舒（戴望舒） | 576/713 | corpus_freq 低 |
| 思成（梁思成） | 357/713 | 同上 |
| 清泉（README 旗舰案例） | 11727/11857 | 平平 + 双声双降权 |
| 千里 / 四方 / 百年 / 一生 | 1-5 名 | 语料高频 = 陈词滥调 |

**根因**：频次类信号在极端处与好名负相关。D-005 已发现人口频次降序产生
「志刚/晓东」，本轮发现语料词频降序产生「千里/百年/四方」——两个频次
都奖励「常见」，而好名的共性是「两个世界都罕见」（徽音 1/1、望舒 1/8）。

**探索过的方案（都有实测反例，留档防复蹈）**：

1. `corpus_freq` 升序（独特性优先）——诗经小语料下把「言告/顷筐/兔罝」
   这类诗法套语顶到最前（人口 0、语料恰好 2 次）。
2. `dual_rarity = min(语料词频, 人口频次)` 全局排序——全量语料下
   「一生」min=5 压过「清扬」min=7。
3. 名篇层内人口降序（证据强度优先）——16,448 候选模拟中前 25 名变成
   「志刚/国成/大宝/顺利」（论语/周易中出现一次的高频人名），D-005 复现。

**最终方案**（在 16,448 个全量候选上模拟选定）：

```
排序：has_numeral → source_fame → dual_rarity → population_freq:asc → corpus_freq:asc
门槛：人口 ≥ 1（有人叫过） 或 叠字且语料 ≥ 2（叠音是《诗经》构词法）
```

- `has_numeral`：含数字字垫后（四方/百年/一生/万邦）。
- `source_fame`：任一出处属名篇目录（`config/famous_sources.txt`：
  诗经/论语/周易整书；楚辞核心篇目＝王逸《楚辞章句》；唐诗三百首＝蘅塘退士；
  宋词三百首＝朱祖谋）。选本收录是可引用、可核对的经典度证据。
- `dual_rarity` 只在名篇层内使用（层外失真，见反例 2）。
- 人口升序＝不撞名（原 `--rare` 的语义被默认序吸收，该参数移除）。

**验收**（改造时为 16,448 旧候选上的模拟；2026-10 全量语料恢复后已**实测**取代，
35,303 候选）：

| 词 | 改造前（旧全量/旧口径） | 实测名次 |
|---|---|---|
| 呦呦 | 无（门槛杀死） | **#263（前 0.7%）** |
| 徽音 | 无（门槛杀死） | **#880（前 2.5%）** |
| 乔木 | #558/16448 | #1704（前 4.8%） |
| 清扬 | 中游偏后 | #2009（前 5.7%） |
| 望舒 | #8700/16448 | #2029（前 5.7%） |
| 修竹 | 中游 | #2043（前 5.8%） |
| 思成 | 中游偏后 | #2524（前 7.1%） |
| 清泉 | #11727/11857 | #2635（前 7.5%） |
| 千里/四方/百年/一生/秋水 | 榜首集团 | 95-96% |

实测比模拟略深（候选池 16k→35k，pop≥1 门槛放进了更多中游词），
但方向与量级一致，验收标准（公认好名靠前、平庸词垫底）成立。

**配套修正**：

- 叠字名豁免同部首剔除（呦呦=口+口 是修辞典故，不是桢柏式同义堆叠）。
- 停用字表补「女」（通假「汝」，杀掉「今女」这类垃圾）。
- `Hit.titles` 记录全量出处坐标：`max_sources=3` 的截断曾让 清泉 的
  山居秋暝 漏出名篇判定。

**残留**：思成/清泉的客观天花板约前 4%（它们的人口/语料计数都是中游，
能抬它们只有「名人名对照表」，那是循环论证，不做）。小语料（--books 诗经）
下 corpus_freq 被压缩，dual 分层失真，思成/清扬名次偏低——corpus_freq
本来就是相对量（SPEC §2.2）。另外，pop=0 的叠字名按 min 语义取 dual=0，
会占据榜首一小段（呦呦 #1 即来自此层）——属可解释的呈现特征；
不喜叠字者可在 `rank.order` 的 dual_rarity 前加 `same_final`（叠字必然同韵母）。

## D-008 · 音韵键从默认排序中退位

**状态**：已采纳

**背景**：旧默认序前两键是 `pingze_interleave`（平仄交错）和
`same_initial/same_final`（同声母/韵母惩罚）。

**为什么退**：

1. **平仄交错不是好名特征**。公认好名里 徽音/呦呦/思成/清扬/清泉 全是平平，
   李白（仄仄）/杜甫（仄仄）/王维（平平）也不过交错。它作为首键把
   平平好名系统性压到非交错词之后。
2. **同声母惩罚与 D-004 自相矛盾**。D-004 明说双声（清泉/参差）是修辞美
   「只标记不排除」，但排序里它排在词频之前——事实上的软排除。
   清泉因此排到 11727/11857。

**改法**：三个音韵键保留为**可用键**（`pingze_interleave` / `same_initial`
/ `same_final`），用户可在 `rank.order` 里自行启用；默认序不含它们。
`--require-pingze` 命令行过滤保留（展示层过滤，不影响排序）。

**教训**：一个特征「可核对」不等于「该作为默认排序键」——排序键的
默认值本身也是口径，需要证据支撑。

## D-009 · 全名听感层：姓 + 名一起念的四个维度

**状态**：已采纳（2026-10）

**背景**：D-007 解决了「名字本体」的排名，但用户指出关键缺口：听感是
**姓 + 名三个字一起念**形成的，而管线里姓氏只参与三个连接点硬规则
（同字/同声母/同韵母，且只看名首字）。实测聂姓运行，榜首出现
「聂趯趯 4-4-4」「聂彊彊 4-4-4」（三字同调）、「聂喓喓 4-1-1」——
全名声调旋律完全没被评估。

**方案**：四个**可独立核对的客观量**做成排序键（不发明加权分，无姓时
取中性值不惩罚）：

| 键 | 定义 | 依据 |
|---|---|---|
| `tone_variety` | 全名（姓+名）声调去重数，3>2>1 | 同调连念旋律单调（聂趯趯 4-4-4） |
| `junction_liasion` | 姓韵尾鼻音(-n/-ng) + 名首字零声母 | 「陈恩/王安」连读吞音。注意 ang 结尾是 g，首版只查了 n |
| `tail_open` | 尾字韵母洪细：按**韵腹**判（介音不算），韵腹 a/o/e/u=洪，i/ü=细 | 元音响度序 a>o>e>u>ü>i；介音不改响度，故 泉(üan)/扬(iang) 判洪 |
| `full_tones` | 全名声调序列（CSV 列，供人工核对） | — |

**位置取舍**：`tone_variety`/`junction_liasion` 放在 dual_rarity 之后
（名好不好优先于连起来顺不顺）；`tail_open` 放**最末**——徽音(in)/
清泉(üan 判洪后无碍)/细音收尾的好名不应被压制，它只做并列裁决。

**为什么只降权不剔除**：王维(2-2)、徽音(1-1) 是同调好名——声调多样性
是统计倾向不是硬约束。三连同调确实最差，垫后即可。

**验证**：聂姓运行，聂趯趯/聂彊彊/聂晏晏（4-4-4）从榜首跌到 #82-84；
16,448 全量候选模拟，六个验收名位置不变（呦呦 #1、徽音 #20、清扬 #347、
望舒 #381、思成 #581、清泉 #615，全部前 4%）。

**用户偏好适配**：各听感维度的优先级是主观的。想调整只需改
`config/default.yaml` 的 `rank.order` 键顺序（如把 `tail_open` 提前、
或把 `tone_variety` 放到 dual_rarity 之前），无需改代码。

## 待决

以下问题**还没有结论**，接手的人可以advance：

1. **虚词停用表的依据**。当前 210 字是按噪声情况调的，没有文献依据。应该用《古代汉语虚词词典》或王力《古代汉语》的虚词表交叉验证。
2. **要不要加词性过滤**。加了能滤掉「百年」「一生」，但要引入 HanLP/LTP，与「零重依赖」的设计冲突。
3. **出处知名度怎么量化**。现在用「跨书数」代理。《唐诗三百首》收录目录可能是更好的信号，但只覆盖唐诗。
4. **要不要保留「八字用神」那一层**。前一版做过（见 `../qiming/`），它是独立体系，可以与摘词法叠加，也可以不叠。目前**没有**集成进本项目。

## D-011 · 地名碎片标记：语境证据 + 地名志

**状态**：已采纳（2026-10，"无词性判断"P0 缺口的第一阶段）

**背景**：D-010 偏好后的榜单仍有两类垃圾混在中上游：
地名碎片（武强 #17「官武强**縣**尉」）与叙事碎片（利维/锡爵）。
实测前 100 名中：地名类 2 个（可客观识别），叙事类 2-3 个（不可客观识别）。
词性标注器（HanLP/LTP）被否决：现代汉语模型对先秦文本不可靠 + GB 级依赖
+ 恰好判不了最有价值的类别。

**方案**：两条可核对证据，合成一个降权键 `place_flag`（不剔除）：

1. **语境证据（严格全称判定）**：2-gram 的全部非句末右邻都属于行政区划
   后缀表（县縣郡州府都邑镇京），且后缀出现 ≥2 次。
   武强 右邻={縣:1,县:1} ✓；乔木 31 种右邻含 1 个「都」✗。
   首版"任一命中"曾把 乔木(#504→#15530)/功名/黄金 误伤——153 万段里
   偶然共现必然发生，全称判定是必要的。
